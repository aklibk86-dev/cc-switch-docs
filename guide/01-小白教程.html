生命不息，折腾不止。

这篇是给完全没碰过命令行的小白看的：教你用一个叫 CC Switch 的小工具，把自己的 AI 中转站（比如 ai.aklibk.com）接进 Claude Code，不用官方账号、不用绑海外卡，一个 API Key 就能用上 Claude、GPT 全家桶，而且想切回官方配置随时切，全程点点点，不用碰任何配置文件。

一、先搞懂三件事（60 秒） ​

  • Claude Code：现在最火的 AI 编程助手，在终端里陪程序员写代码，你问它答，能帮你改代码、跑命令。
  • AI 中转站：把 Claude、GPT、Gemini 这些国外模型的接口"搬"到国内能直接访问的地址。你不用注册官方账号、不用绑信用卡，在中转站充点钱、拿一个 Key，就能调用所有模型。
  • CC Switch：一个电脑上的小工具，专门管理 Claude Code 这些 AI 工具的"配置"。以前换模型要手动改配置文件（小白看到 JSON 就头大），CC Switch 把它变成了点一下切换。

一句话：CC Switch 就是 Claude Code 的"遥控器"，中转站就是"电视信号源"，遥控器一按就换台。

二、准备工作 ​

（2 分钟）

只需要准备两样东西：

① 一个中转站的 API Key

  • 注册你的中转站账号（比如 ai.aklibk.com）
  • 登录后台 → 找到 API Keys / 令牌 页面 → 创建新 Key
  • 复制这串 sk- 开头的字符，先存记事本里，一会儿要粘

② 安装 Node.js

  • 打开 https://nodejs.org/zh-cn ，下载 LTS 版安装包
  • 一路"下一步"装完（啥都不用改）
  • 验证：按 Win + R，输入 cmd 回车，在弹出的黑窗口里输入：
    node --version
    看到 v18 或更高版本号就说明装好了

三、第一步：下载 CC Switch（1 分钟） ​

  • 打开官网 https://ccswitch.io，或去 GitHub Releases 页面下载
  • ⚠️ 只从官网或官方 GitHub 下载！ 网上任何要你付费、充值、登录的"CC Switch"网站都是山寨，千万别碰
  • Windows 用户选 CC-Switch-v{版本号}-Windows-Portable.zip（绿色版，免安装）
  • 解压后双击 CC-Switch.exe，软件就打开了（任务栏会多个小图标）

四、第二步：把你的中转站加进去（1 分钟） ​

打开 CC Switch 主界面，按下面 6 步走：

  1. 点右上角的 + 号，打开添加面板
  2. 选 Claude Code（给哪个工具用就选哪个，后面还能加 Codex/Gemini）
  3. 预设那里选 自定义（中转站都是自定义填参数）
  4. 填三个关键信息：
    • 名称：随便写，比如 我的中转站
    • API 地址（Base URL）：填中转站给你的接口地址，例如 https://ai.aklibk.com
    • API Key：粘贴刚才复制的那串 sk- 开头的 Key
  5. 点模型输入框旁边的 获取模型 按钮——CC Switch 会自动去中转站拉取可用模型列表，点选一个（比如 claude-sonnet-4-5）
  6. 点 添加，完事

小技巧：如果「获取模型」点不动或报 401，八成是 API 地址或 Key 填错了，回去检查一下。

五、第三步：切换并打开 Claude Code（30 秒） ​

  1. 在主界面找到刚添加的供应商，点一下它（选中 = 当前生效）
  2. 打开终端（Win+R → cmd），输入：
    claude
  3. 出现对话界面

，随便问一句"你好"——能回复就说明全部搞定！

想切回官方账号？ 再点回原来的供应商（比如 Claude 官方）就行。CC Switch 自动帮你备份和切换配置文件，你永远不用手动碰配置文件。

六、常见问题（救急用） ​

问题解决方法
报 401 / 连不上API 地址或 Key 填错了，回去核对；地址结尾要不要 /v1 以中转站文档为准
拉不到模型列表手动在模型框里填模型名（如 claude-sonnet-4-5）
下载的软件打不开右键 → 属性 → 安全 → 勾选"解除锁定"
Claude Code 报错终端运行 claude doctor 看诊断信息
用了中转站后想换模型回 CC Switch 编辑供应商，换模型再切一次

七、总结 ​

三步走：下载 CC Switch → 填中转站地址和 Key → 点一下切换。就这么简单，全程不碰代码、不碰配置文件。

想要 Claude / GPT / Gemini 全家桶一个 Key 通吃、国内直连免绑卡、人民币按量付费？可以试试 Aklibk API 中转站（ai.aklibk.com），新用户充值还有优惠。
